daily-finance-brief

daily-finance-brief 是開發者本人自用的「每日財經晨報」寄送工具。程式只在開發者本人的 Windows 電腦上執行，每天產生一份財經晨報，並透過 Gmail API 寄到開發者本人的信箱。

使用的 Google 權限

  • 只使用 https://www.googleapis.com/auth/gmail.send（以使用者名義寄送電子郵件）。
  • 不讀取、不修改、不刪除任何郵件，也不存取聯絡人或其他 Google 資料。

服務對象

本工具不對外提供服務，唯一使用者為開發者本人。

隱私權政策 Privacy Policy

English

daily-finance-brief is a personal tool used only by its developer. It runs on the developer's own Windows computer, generates a daily financial market brief, and sends it to the developer's own mailbox through the Gmail API. It requests only the gmail.send scope and never reads, modifies or deletes email. It is not offered to the public.
