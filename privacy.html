daily-finance-brief 隱私權政策

生效日期：2026-10-27

1. 適用範圍

daily-finance-brief 是開發者本人自用的工具，只在開發者本人的電腦上執行，不對外提供服務。

2. 存取的 Google 使用者資料

  • 本工具只申請 Gmail API 的 gmail.send 權限，用途僅限於把每日財經晨報寄到開發者本人的信箱。
  • 本工具不讀取、不搜尋、不修改、不刪除任何郵件，也不存取聯絡人、雲端硬碟或其他 Google 資料。

3. 資料的儲存與保護

  • OAuth 授權憑證只儲存在開發者本人的電腦上，並以 Windows 資料保護（DPAPI）加密，只有同一個 Windows 使用者帳號能解密。
  • 寄送紀錄（郵件識別碼、寄送時間、寄送狀態）只儲存在本機。
  • 上述資料不會上傳到任何伺服器。

4. 分享與使用限制

本工具不會出售、出租、分享或轉移任何 Google 使用者資料給第三方，也不會將資料用於廣告。

daily-finance-brief 對於從 Google API 取得之資訊的使用與轉移，將遵守 Google API 服務使用者資料政策，包括其中的「限定使用」(Limited Use) 規定。

5. 撤銷授權

可隨時在 Google 帳戶的第三方存取權頁面 移除本工具的存取權；移除後本工具即無法再寄信。

6. 聯絡方式

如有疑問，請透過 Google OAuth 同意畫面上列出的開發人員支援信箱聯絡。

Privacy Policy (English)

Effective date: 2026-10-27

daily-finance-brief is a personal tool used only by its developer on the developer's own computer; it is not offered to the public.

  • Data accessed: only the Gmail API gmail.send scope, used solely to send the daily brief to the developer's own mailbox. The tool never reads, searches, modifies or deletes email and does not access contacts, Drive or any other Google data.
  • Storage: OAuth credentials are stored only on the developer's computer, encrypted with Windows DPAPI. Send records (message ID, time, status) are stored locally. Nothing is uploaded to any server.
  • Sharing: no Google user data is sold, rented, shared or transferred to third parties, and none is used for advertising.
  • daily-finance-brief's use and transfer of information received from Google APIs will adhere to the Google API Services User Data Policy, including the Limited Use requirements.
  • Revocation: access can be removed at any time at https://myaccount.google.com/permissions.
  • Contact: via the developer support email shown on the Google OAuth consent screen.
